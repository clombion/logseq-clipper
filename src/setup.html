Logseq Web Clipper

Clip web pages directly into Logseq as structured, searchable pages with metadata.

This extension extracts content from any web page, converts it to Logseq's block format, and saves it via Logseq's local HTTP API. It supports templates, highlighting, an AI interpreter, and a clipping log for dedup detection.

Based on Obsidian Web Clipper, adapted for Logseq.

Step 1: Enable the HTTP API server

In Logseq, go to Settings → Features and enable HTTP APIs Server.

Step 2: Start the server

Click the API icon in Logseq's toolbar, then select Start Server.

Tip: Enable "Auto start server" in the API panel's Server configurations so it starts with Logseq.

Step 3: Create an authorization token

In the API panel, go to Authorization tokens → Add new token. Enter a name and value, then paste the token value below.
