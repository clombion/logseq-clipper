Logseq Web Clipper is a free browser extension that lets you highlight pages and save web content to your Logseq graph.

## Install Web Clipper

Install the Logseq Web Clipper extension from the release page or build it from source. See the project README for installation instructions.

- [[Clip web pages]]

- [[Highlight web pages|Highlighter]]

- [[Interpret web pages|Interpreter]]

- [[Troubleshoot Web Clipper|Troubleshooting]]
	- Resolve common issues with Web Clipper.
- [[Templates]]

- [[Variables]]

- [[Logic]]

## Privacy

Logseq Web Clipper saves content locally to your Logseq graph. Your data is not collected, and we do not gather any usage metrics. The code is open source and auditable.
